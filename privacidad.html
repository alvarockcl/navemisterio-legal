Política de privacidad

Aplicación: navemisterio-github · Última actualización: 24 de noviembre de 2026

1. Qué es esta aplicación

navemisterio-github es una herramienta interna que usa el propietario del canal de YouTube La Nave del Misterio (navemisterio) para administrar su propio canal de forma automatizada desde un repositorio privado de GitHub. No es un servicio público y no la usan terceros.

2. Qué datos se usan

Al autorizar la aplicación mediante Google OAuth, se accede a la cuenta de YouTube del propietario con los permisos:

  • youtube.upload: subir videos al canal.
  • youtube: editar título, descripción, etiquetas, privacidad, miniaturas y listas de reproducción de los videos del canal, y leer estadísticas públicas del canal (suscriptores, vistas, me gusta y comentarios).

La aplicación no accede a datos de otros usuarios, no lee mensajes ni comentarios privados y no recopila información de los espectadores del canal.

3. Para qué se usan

  • Publicar y programar videos del propio canal.
  • Mantener actualizada la metadata de esos videos.
  • Generar reportes periódicos de estadísticas del canal para uso interno.

4. Almacenamiento y seguridad

Las credenciales de acceso (token de actualización de OAuth) se guardan cifradas como secrets de GitHub Actions y solo se usan durante la ejecución de los procesos automatizados. Los identificadores de los videos y los reportes de estadísticas se guardan en un repositorio privado de GitHub.

5. Compartir con terceros

Los datos no se venden, no se comparten con terceros y no se usan con fines publicitarios. Solo intervienen Google (YouTube API Services) y GitHub como proveedores de infraestructura.

El uso que hace esta aplicación de la información recibida de las APIs de Google cumple con la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de Uso Limitado.

6. Servicios de YouTube y Google

Esta aplicación usa los servicios de API de YouTube. Al usarla se aplican los Términos de servicio de YouTube y la Política de privacidad de Google.

7. Cómo revocar el acceso

El acceso puede revocarse en cualquier momento desde la configuración de seguridad de tu cuenta de Google. Al revocarlo, la aplicación deja de poder acceder al canal de inmediato.
